Agent installed

This page loads the same two files you drop on your host. The bubble bottom-right is the whole agent — it streams answers, keeps the transcript while the tab is open, and never puts your API key in the page source.

EMBED ON aidekupal.unaux.com

Paste this just before </body> on any page — index.html, the chat, anywhere:

<script>window.AGENT_CONFIG = { endpoint: 'api-ai.php' };</script>
<script src="agent-widget.js" defer></script>

Both files sit next to your index.html. Nothing else to install.

FILES

  1. agent-widget.js — the bubble, panel, streaming, transcript, markdown-lite.
  2. api-ai.php — holds your key, adds the system prompt, streams OpenRouter back.
  3. agent-demo.html — this page, only for testing. Not needed on the site.

Check the proxy first: open api-ai.php?health=1 — it should say key_set: true.
