NOV 30

  • The fourth chair opened: Fortress. A pixel-orc tower defence sits beside the other three — nine towers on a 15x10 grid, thirteen monsters, five maps that swap in every five waves, and flyers that go straight over your walls, so the cannon and the mortar cannot touch them. After wave twenty the stage loops with everything at +50%. Every sprite is drawn from a grid of characters on the canvas, so the game carries no pictures at all — nothing to lose.
  • Every chair now has a tag in the file. The feed names fortressBuild the way it names the other three, the hub opens the copy the feed points at, and the game introduces itself as fortress f2 under its HUD — so the picker and the game can never quietly disagree about which build is live.
  • The hall of fame is two boards. The All tab is gone — it added two games together and flattered nobody. 1V1 is the duel board it always was, and Royale is the group game, named for the ladder it now keeps.
  • Royale ranks — Unranked, Herald, Guardian, Crusader, Archon, Legend, Ancient, Divine and Immortal. Every five Royale wins is one step, and the tier is read straight off the wins, so a match you lose never costs you a rank. Every Royale row wears its tier beside the wins, with five pips for the climb into the next one.
  • The ladder can be cleaned without a new season. The maker's window now works on the boards themselves: 1v1 and Royale are reset apart, for one name or for the whole board, and both ask before anything goes. A Royale reset takes the wins, and the tier follows them back to Unranked.

About this page

It is a picker and nothing more: it holds no game code, no scores and no names. Every chair above is a door; the game you walk through is the one that keeps the score.

Before it opens anything it reads one small file on the main branch — labs/pindutan-build.json — which says which build is current and where the game lives. That is why a build you publish tonight is the build everybody plays: nothing here has to be re-uploaded for it to reach them, and no old copy that happened to be sitting on a host can win.

The page keeps itself current the same way. On every open, and on every tap of the strip under the wordmark, it compares the tag it carries with the one in that file, and if a newer hub is out it fetches it, checks it (the HUB-MENU marker, a whole page, its own tag) and hands the page over once. A hub that was just swapped in does not swap again in the same session, so there is no loop to get stuck in.

The game does exactly the same thing one step further down, with the same file. In a chain where every link checks itself, the only thing that has to be right is the file — and it is one line to edit.

If there is no signal, nothing breaks: the strip turns amber, the chairs still answer, and the chair that is built still opens the copy it already knows about.

One thing worth saying plainly: all four chairs are games now, in one file each — labs/pindutan-v21.html for the arena, labs/chess.html for chess, labs/zuma.html for Zumang and labs/fortress.html for Fortress. Each one carries its own tag (v29, c6, m3, f3), and the file above is the only place those tags are compared. Rename a chair here and you rename it everywhere.
